# Demo Video Script (about 3 minutes)

Record your screen while speaking. Keep each part short.

| Time | What to show | What to say |
|---|---|---|
| 0:00-0:20 | Open the live app | "Hi, I am Tarun. This is CareerPilot, my Generative AI capstone for Codomax Digital Solutions. It helps students prepare for jobs using an AI agent." |
| 0:20-0:40 | Show architecture.png | "It combines an LLM API, prompt engineering, RAG, tools and an agent. Documents go through chunking, embeddings and a FAISS vector database. The agent uses tools, including document search." |
| 0:40-1:10 | Upload both sample files, click Process documents | "I upload a resume and a job description. The app splits them into chunks, creates embeddings and stores them in a vector database." |
| 1:10-1:50 | Career Coach: click "Compare my resume with the job description"; open the Agent steps panel | "The agent decides to call search_documents twice, once for the resume and once for the job. Here are the steps. It lists my matching skills, the missing ones and suggestions, with sources." |
| 1:50-2:20 | Study Helper: click "Make a 5-day study plan..." and show the My tasks panel | "Now the agent uses the database tools to add study tasks. They appear in the task panel." |
| 2:20-2:50 | Interview Coach: click "Start a mock interview", answer one question | "In Interview Coach mode it asks a question from the job description. When I answer, it calls a scoring tool that returns structured JSON, and I get a score and feedback." |
| 2:50-3:10 | Show the GitHub repo | "The code and documentation are on GitHub, with a safe tool design, a step limit and error handling. Thank you." |

## How to record
- **Laptop (Windows):** press `Win + G`, click Capture, then Record. Or use any screen recorder.
- **Phone:** use the built-in screen recorder from the quick settings panel.
- Speak slowly and clearly. Speaking in simple English or Hindi is fine.

## How to share the video link
- **YouTube:** upload, set visibility to **Unlisted**, and copy the link.
- **Google Drive:** upload, click Share, set **Anyone with the link** (Viewer), and copy the link.
